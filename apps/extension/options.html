JobSA Settings

Configure how JobSA detects job application forms across the web.

Enable auto-detect on all sites Run form detection on every HTTPS page, not just known ATS platforms. Chrome will ask for your permission before enabling.

What this does

By default, JobSA only auto-detects application forms on 25+ known ATS platforms (Greenhouse, Lever, Workday, etc.). Enabling this option allows auto-detection on any website — useful for companies that use their own custom application systems.

You can disable this at any time, and the permission will be fully revoked.
